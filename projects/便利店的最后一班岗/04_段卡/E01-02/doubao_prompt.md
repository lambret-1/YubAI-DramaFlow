# E01-02 豆包/Seedance 提示词

便利店内，两人隔着柜台相对，熟悉而沉默。
镜1：阿雾走到柜台前，把热牛奶放上柜台，小夜站在柜台后。固定镜头。
切：镜2：小夜扫码，余光看到阿雾左眼角下的泪痣。固定镜头特写。
切：镜3：阿雾低头轻声说"老样子"。固定镜头近景。
切：镜4：小夜手指停顿在扫码枪上，迟疑。固定镜头大特写。
切：镜5：两人沉默相对，冰箱嗡嗡声。固定镜头。
切：镜6：阿雾睫毛轻颤，眼眶微红。固定镜头特写。
全程冰箱嗡嗡声，扫码枪"滴"，牛奶盒放柜台轻响。配乐：低音弦乐长音加入，钢琴持续，情绪微紧张。
@阿雾_侧 @小夜_正 @便利店_夜 @热牛奶盒 @阿雾_泪
9:16 竖屏，15 秒，运镜平缓。
不要：变形、闪烁、人物变脸、多余肢体。
