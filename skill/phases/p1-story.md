# P1 故事层 — 从一句话到 4 段短剧剧本

## 输入
- 用户一句话题材（例："社畜穿越成猫"）
- 目标受众 / 基调（可选）

## 做什么
1. 把一句话扩成 **60 秒大纲**，强制拆成 **4 个 segment**：
   - S1 钩子（0–15s）：抛出冲突/异常
   - S2 发展（15–30s）：冲突升级或反转
   - S3 高潮（30–45s）：情绪峰值
   - S4 收尾（45–60s）：反转/留白/钩子到下集
2. 写剧本：每段只写 **5–6 个 beat**（对应镜头），每个 beat 一句话动作 + 一句台词/旁白。
3. AI 可行性自评：逐 beat 标难度 🟢🟡🔴⛔。

## 产物
- `01_故事/大纲.md`
- `01_故事/剧本.md`
- `01_故事/可行性评估.md`（含难度分布表）

## Gate1（不过不进 P2）
- [ ] 恰好 4 个 segment
- [ ] 主角单人镜头占比 > 60%
- [ ] 🔴/⛔ 镜头总数 ≤ 3 个（占比 < 15%）
- [ ] 无"打斗、多人混战、精确文字、手部精细动作"等 ⛔ 元素（或已改写为替代）
- [ ] 场景总数 ≤ 4 个（每个 segment 一个主场景）
