# P3 资产层 — 人物卡 + 场景卡（只产提示词）

## 输入

- P2 的 global_anchor
- P1 剧本里的人物/场景列表
- P1 的 `01_故事/场景清单.md`（场景编码与时段）

## 做什么

1. 为**每个角色**填一张人物卡（schema 见 `schemas/character-card.schema.md`）：
   - 所有角色统一出三视图：`<角色>_正面 / <角色>_侧面 / <角色>_背面` 三条全身图
   - 不做表情变体、动作变体
2. 为**每个场景**写场景卡：基础描述 + 时间变体（`教室_白天 / 教室_黄昏 / 教室_夜晚`）。
3. 所有提示词自动拼 `{anchor_en}`。
4. **生成 `03_资产/manifest.md`**：把所有资产编码、文件路径、描述登记成表（模板见 `templates/manifest.template.md`）。
5. 列出“用户需要去外部跑的图清单”（清单化，不代跑）。

## 资产编码规则（写死）

- 人物：`<角色全名>_<变体>`，变体词表 **`正面 / 侧面 / 背面`**（三视图全身，固定三个）
- 场景：`<场景名>_<时段>`，时段词表 `白天/黄昏/夜晚/清晨`
- 道具：直接 `<道具名>`
- 编码一旦写入 manifest.md，**后续 P4 不许改名**

## 产物

- `03_资产/人物/<角色名>.md`
- `03_资产/场景/<场景名>.md`
- `03_资产/manifest.md`（资产注册表）
- `03_资产/待跑图清单.md`（一张表：资产编码 → 提示词 → 建议工具 → 用途）

## Gate3

- [ ] 每个角色恰好 3 个资产编码（正面/侧面/背面）
- [ ] 每条提示词首行都是 anchor_en
- [ ] 每条提示词都有 negative
- [ ] manifest.md 已注册全部资产编码
- [ ] P1 场景清单中的每个场景都已在 manifest.md 注册
- [ ] 用户已拿到待跑图清单（不要求已跑完）
