# P3 资产层 — 人物卡 + 场景卡（只产提示词）

## 输入
- P2 的 global_anchor
- P1 剧本里的人物/场景列表

## 做什么
1. 为**每个主角**填一张人物卡（schema 见 `schemas/character-card.schema.md`）：
   - 主角：`林小雨_正 / 林小雨_侧 / 林小雨_笑` 三条提示词
   - 配角：只出 `<角色>_正` 一条
2. 为**每个场景**写场景卡：基础描述 + 时间变体（`教室_白天 / 教室_黄昏 / 教室_夜晚`）。
3. 所有提示词自动拼 `{global_anchor_en}`。
4. **生成 `03_资产/manifest.md`**：把所有资产编码、文件路径、描述登记成表（模板见 `templates/manifest.template.md`）。
5. 列出"用户需要去外部跑的图清单"（清单化，不代跑）。

## 资产编码规则（写死）

- 人物：`<角色全名>_<变体>`，变体词表 `正/侧/背/笑/哭/怒/惊/坐/走`
- 场景：`<场景名>_<时段>`，时段词表 `白天/黄昏/夜晚/清晨`
- 道具：直接 `<道具名>`
- 编码一旦写入 manifest.md，**后续 P4/P5 不许改名**

## 产物
- `03_资产/人物/<角色名>.md`
- `03_资产/场景/<场景名>.md`
- `03_资产/manifest.md`（资产注册表）
- `03_资产/待跑图清单.md`（一张表：资产编码 → 提示词 → 建议工具 → 用途）

## Gate3
- [ ] 主角每人 ≥ 3 个资产编码（正/侧/笑）
- [ ] 每条提示词首行都是 global_anchor
- [ ] 每条提示词都有 negative
- [ ] manifest.md 已注册全部资产编码
- [ ] 用户已拿到待跑图清单（不要求已跑完）
