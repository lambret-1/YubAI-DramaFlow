# P3 资产层 — 人物卡 + 场景卡（只产提示词）

## 输入
- P2 的 global_anchor
- P1 剧本里的人物/场景列表

## 做什么
1. 为**每个主角**填一张人物卡（schema 见 `schemas/character-card.schema.md`）：
   - 主角：front / side / smile 三条提示词
   - 配角：只出 front 一条
2. 为**每个场景**写场景卡：基础描述 + 时间变体（晨/昏/夜）。
3. 所有提示词自动拼 `{global_anchor_en}`。
4. 列出"用户需要去外部跑的图清单"（清单化，不代跑）。

## 产物
- `03_资产/人物/<角色名>.md`
- `03_资产/场景/<场景名>.md`
- `03_资产/待跑图清单.md`（一张表：提示词 → 建议工具 → 用途）

## Gate3
- [ ] 主角每人 ≥ 3 条提示词
- [ ] 每条提示词首行都是 global_anchor
- [ ] 每条提示词都有 negative
- [ ] 用户已拿到待跑图清单（不要求已跑完）
