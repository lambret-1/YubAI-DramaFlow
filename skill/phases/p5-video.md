# P5 视频提示词层 — 双模板逐镜输出

## 输入
- P4 的所有 `shot_XX.json`

## 做什么
**逐镜**生成两份提示词，分别落到两个目录：

### 5.1 豆包 / Seedance 版
按 `reference/豆包视频提示词模板.md`：
```
{场景}。{主体}（{情绪}），{动作}。{镜头运动}。{光线}。@参考图1 @参考图2
9:16 竖屏，{X} 秒，运镜平缓。
```

### 5.2 MiniMax H3 多参考版
按 `reference/minimax-h3-多参考模板.md`：
```
[Shot N] {画面描述}。
角色外形参考图1（{角色名}），场景参考图2，保持身份一致。
{时长} 秒，9:16 竖屏。
```

并附一张"上传清单"：告诉用户在 Hailuo 网页按什么顺序传哪几张图。

## 产物
- `05_视频提示词/豆包_seedance/shot_01.txt …`
- `05_视频提示词/minimax_h3/shot_01.txt …`
- `05_视频提示词/上传清单.md`（H3 参考图编号 ↔ 资产文件路径）

## Gate5
- [ ] 每个 shot 都有两份提示词文件
- [ ] 豆包版含 `@参考图` 引用
- [ ] H3 版显式声明"图N=谁"
- [ ] 两份提示词的动作/时长与 shot.json 一致
