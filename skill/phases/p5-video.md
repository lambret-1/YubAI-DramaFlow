# P5 视频提示词层 — 双模板逐镜输出

## 输入
- P4 的所有 `shot_XX.json`
- `03_资产/manifest.md`（资产注册表）

## 做什么
**逐镜**生成两份提示词，分别落到两个目录：

### 5.1 豆包 / Seedance 版
按 `reference/豆包视频提示词模板.md`：
```
{场景}。{主体}（{情绪}），{动作}。{镜头运动}。{光线}。@{编码1} @{编码2}
9:16 竖屏，{X} 秒，运镜平缓。
```
其中 `@{编码}` 必须与 `shot.json.image_refs` 一一对应。

### 5.2 MiniMax H3 多参考版
按 `reference/minimax-h3-多参考模板.md`：
```
[Shot N] {画面描述}。
角色外形参考图1={编码1}，场景参考图2={编码2}，保持身份一致。
{时长} 秒，9:16 竖屏。
```
并附一张"上传清单"：图N → 资产编码 → 文件路径（从 manifest.md 查）。

## 产物
- `05_视频提示词/豆包_seedance/shot_01.txt …`
- `05_视频提示词/minimax_h3/shot_01.txt …`
- `05_视频提示词/上传清单.md`（H3 参考图编号 ↔ 资产编码 ↔ 文件路径）

## Gate5
- [ ] 每个 shot 都有两份提示词文件
- [ ] 豆包版 `@编码` 与 `shot.json.image_refs` 完全一致
- [ ] H3 版 `图N=编码` 与上传清单一致
- [ ] **`image_refs` 中每个编码都在 manifest.md 注册**（未注册的直接报错，不生成提示词）
- [ ] 两份提示词的动作/时长与 shot.json 一致
