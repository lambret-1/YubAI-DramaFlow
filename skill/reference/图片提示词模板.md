# 🖼️ 图片提示词模板（适配即梦 / Seedream / GPT-Image 官方结构）

> 半自动模式：本 Skill 不调用生图工具，只产可复制提示词。

## 通用公式

```
{global_anchor} + {主体描述} + {服饰/表情/姿态} + {场景/环境} + {光线/氛围} + {质量词}
```

## 中文模板（给即梦/豆包生图）

```
{风格锚定中文}。{角色名}，{年龄}岁，{脸型}，{眼睛}，{发型}。
{服装描述}，{表情}，{姿态}。
{场景描述}，{光线描述}。
高质量，精细细节，8K。
```

## 英文模板（给 Midjourney / Flux / GPT-Image）

```
{global_anchor_en}.
{consistency_keywords.en},
wearing {outfit}, {expression}, {pose}.
{scene description}, {lighting}.
masterpiece, best quality, highly detailed, 8K.
--no blurry, deformed, watermark, text
```

## 静帧（P4 给图生视频当首帧）专用

```
{global_anchor_en}
{consistency_keywords.en},
{本镜动作的"起始瞬间"定格描述}。
{场景}，{光线}。
水平构图，主体居中，预留顶部和底部安全区（9:16 竖屏）。
masterpiece, best quality, 8K.
```

### 为什么要"起始瞬间"？

图生视频模型从首帧开始运动，所以首帧要选**动作即将发生的那一帧**，而不是动作中间。

| 动作 | 错误首帧 | 正确首帧 |
|---|---|---|
| 走路 | 脚抬到一半 | 站立、重心前倾 |
| 转头 | 脸已经转到侧面 | 脸正对镜头、眼神微斜 |
| 落泪 | 眼泪挂在脸上 | 眼眶微红、泪将落未落 |

## 负面词（统一）

```
blurry, low quality, deformed, bad anatomy, extra limbs, missing limbs,
watermark, text, signature, bad face, ugly face, mutation, disfigured
```
