# 🐦 MiniMax H3 全能参考（Omni Reference）提示词模板

> H3 支持最多 9 张参考图 + 3 段参考视频 + 音频。本模板适配"多参考模式"。
> **资产引用统一用中文编码**：`图1=林小雨_正`、`图2=教室_白天`，编码必须在 manifest.md 注册。

## 核心语法

H3 把所有参考素材**编号**（图1、图2、视频1、音频1...），在提示词里显式声明"谁参考谁"。

```
[Shot N] <镜头描述>。<角色/场景/节奏引用>。
```

## 官方典型句式

> "男女主外形参考图1，场景参考图2，保持身份一致。"
> "Use Images 1-6 as assets. Match Reference Video 1 closely for shot rhythm, transition language, and music."

## 单镜模板（P5 直接套用）

```
[Shot {N}] {画面描述：主体 + 动作 + 镜头运动 + 光线氛围}。
角色外形严格参考图1={资产编码1}，场景参考图2={资产编码2}，保持服装与面部一致。
时长 {X} 秒，{9:16 竖屏 / 16:9}，{运镜速度}。
```

## 范例（对应 shot S01_03，image_refs=["林小雨_正","教室_白天"]）

```
[Shot 3] 林小雨侧脸靠窗，午后阳光斜射，睫毛轻颤，目光落在课本上。
角色外形严格参考图1=林小雨_正，场景参考图2=教室_白天，保持面部与校服一致。
镜头从侧面缓慢推进到中近景。时长 3 秒，9:16 竖屏，运镜平缓。
```

## 多镜连打模板（一个提示词出整段）

```
integrated_multimodal_description:
[Shot 1] 教室全景，阳光透过窗户。角色参考图1=林小雨_正、图2=李凡_正，场景参考图3=教室_白天。固定镜头，3秒。
[Shot 2] 林小雨特写，表情紧张。参考图1=林小雨_笑 面部特征。缓慢推近，2秒。
[Shot 3] 李凡中景，坐下。参考图2=李凡_正。固定镜头，3秒。
整体保持日漫风格，暖色调。节奏与转场参考视频1。
```

## 上传清单（每镜必附）

告诉用户在 Hailuo 网页按什么顺序传哪几张图：

| 编号 | 资产编码 | 文件路径 |
|---|---|---|
| 图1 | 林小雨_正 | `assets/人物/林小雨/正.png` |
| 图2 | 教室_白天 | `assets/场景/教室/白天.png` |

## 硬规则

1. **必须显式声明"图N=资产编码"**，H3 才会锁定身份
2. 一次调用最多 3 个 shot（连打模式），超过就拆多次
3. 不要写负面词（H3 对负面词不敏感，靠参考图约束）
4. 情绪和动作要写得**具体**：不要"她很悲伤"，要"她低头，眼泪滑落，嘴角微颤"
5. **上传清单里的编码必须与 `shot.json.image_refs` 完全一致**
