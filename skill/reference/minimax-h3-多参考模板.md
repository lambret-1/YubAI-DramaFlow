# 🐦 MiniMax H3 全能参考（Omni Reference）提示词模板

> H3 支持最多 9 张参考图 + 3 段参考视频 + 音频。本模板适配"多参考模式"。

## 核心语法

H3 把所有参考素材**编号**（图1、图2、视频1、音频1...），在提示词里显式声明"谁参考谁"。

```
[Shot N] <镜头描述>。<角色/场景/节奏引用>。
```

## 官方典型句式

> "男女主外形参考图1，场景参考图2，保持身份一致。"
> "Use Images 1-6 as assets. Match Reference Video 1 closely for shot rhythm, transition language, and music."

## 单镜模板（P5 直接套用）

```
[Shot {N}] {画面描述：主体 + 动作 + 镜头运动 + 光线氛围}。
角色外形严格参考图1（{角色名}），场景参考图2（{场景名}），保持服装与面部一致。
时长 {X} 秒，{9:16 竖屏 / 16:9}，{运镜速度}。
```

## 多镜连打模板（一个提示词出整段）

```
integrated_multimodal_description:
[Shot 1] 教室全景，阳光透过窗户。角色参考图1(林小雨)、图2(李凡)，场景参考图3(教室白天)。固定镜头，3秒。
[Shot 2] 林小雨特写，表情紧张。参考图1面部特征。缓慢推近，2秒。
[Shot 3] 李凡中景，坐下。参考图2。固定镜头，3秒。
整体保持日漫风格，暖色调。节奏与转场参考视频1。
```

## 参考素材编号约定（用户在 Hailuo 网页按此顺序上传）

| 编号 | 内容 | 来源 |
|---|---|---|
| 图1 | 主角正面参考图 | P3 人物卡 front_view |
| 图2 | 主角侧面/表情参考 | P3 人物卡 |
| 图3..N | 配角 / 场景参考图 | P3 |
| 视频1（可选） | 节奏参考片（比如一段你喜欢的短剧） | 用户自备 |
| 音频1（可选） | BGM | P6 配乐清单 |

## 硬规则

1. **必须显式声明"图N=谁"**，H3 才会锁定身份
2. 一次调用最多 3 个 shot（连打模式），超过就拆多次
3. 不要写负面词（H3 对负面词不敏感，靠参考图约束）
4. 情绪和动作要写得**具体**：不要"她很悲伤"，要"她低头，眼泪滑落，嘴角微颤"
