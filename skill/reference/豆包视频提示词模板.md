```

镜1：{画面}。固定/运镜。
切：镜2：{画面}。固定/运镜。
切：镜3：{画面}。
...
全程声景：{雨声/冰箱声...}。配乐：{钢琴单音...}。
@{编码1} @{编码2} ...
9:16 竖屏，15 秒。
```

## 引用语法

| 引用 | 写法 | 说明 |
|---|---|---|
| 人物 | `@小夜_正` | 编码必须在 manifest.md 注册 |
| 场景 | `@便利店_夜` | 同上 |
| 道具 | `@黑伞` | 同上 |
| BGM | `@配乐_钩子段.mp3` | 部分版本支持 |

## 硬规则

1. **一段 15 秒一次生成**，不要拆成单镜多次
2. 镜与镜之间用"切："分隔，每镜 2–4 秒
3. 声景和配乐写在段末，不写在每镜里
4. `@编码` 必须与段卡.md 的 `refs` 数组一一对应
5. 台词不写在豆包提示词里（豆包对口型弱，台词靠后期 TTS 贴）
