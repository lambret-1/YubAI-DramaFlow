# 🎥 豆包 / Seedance（即梦）视频提示词模板

> 适配火山引擎 Seedance 2.0/2.5 + 即梦 AI 官方推荐结构。

## 官方公式

```
【场景】+【主体】+【动作】+【镜头】+【氛围/风格】+【@引用素材】
```

## 推荐句子结构（官方）

```
镜头运动 + 说话角色情绪 + 说话状态(说话/哭泣/唱歌/沉默) + 具体动作 + (可选)背景事件
```

## 单镜模板（P5 直接套用）

```
{场景描述}。{主体}（{情绪}），{具体动作}。{镜头运动描述}。
{氛围/光线}。@参考图1 @参考图2
```

## 范例（对应 shot S01_03）

```
教室窗边，午后阳光斜射。林小雨（心情平静，略带羞涩），侧脸微低，睫毛轻颤，目光落在课本上。
镜头从侧面缓慢推进到中近景。暖金色逆光，空气中有细小灰尘浮动。
@林小雨_校服_正面 @教室_白天
9:16 竖屏，3 秒，1080P，24fps，运镜平缓无抖动。
```

## 引用语法

| 引用 | 写法 |
|---|---|
| 角色参考图 | `@角色_服装_角度.png` |
| 场景参考图 | `@场景名_时段.png` |
| 首帧图 | 工具内上传首帧，提示词里**不要再描述静态外观**（只描述运动） |
| BGM | `@xxx.mp3`（部分版本支持） |
| 前一段视频衔接 | `[@Video1] + [转场描述] + 衔接到 [@Video2]` |

## 硬规则

1. **首帧图模式下，提示词只写"运动 + 变化"**，不要重复描述人物长相（图已经给了）
2. 镜头运动必须写**方向 + 速度**：缓慢推近 / 快速横移 / 固定
3. 时长写在末尾（≤5 秒为默认安全值）
4. 负面词另起一段：`不要：变形、闪烁、人物变脸、多余肢体`
