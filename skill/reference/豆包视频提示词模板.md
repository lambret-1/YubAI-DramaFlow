# 🎥 豆包 / Seedance 段级提示词模板

> 适配火山引擎 Seedance 2.0/2.5 + 即梦 AI。**一段 = 一次生成 = 15 秒 = 5–6 镜。**

## 结构（段级）

```
@编码1 @编码2 ...

【镜头1】
焦距：...
机位：...
构图：...
运镜：...
景别：...
画面：...
台词：{}
视线落点：...
焦点：...
稳定性：...

【镜头2】
...

<环境音>
（配乐）

【约束】画面无字幕，不要生成任何文字或字幕
```

## 字段说明

| 字段 | 取值 |
|---|---|
| 焦距 | 50mm（标准）/ 85mm（长焦特写）/ 35mm（广角环境）/ 100mm（微距大特写） |
| 机位 | 平视 / 俯视 / 仰视 / 正面 / 侧面45° / 背面 |
| 构图 | 中心 / 对称 / 框架 / 三分法 |
| 运镜 | 固定 / 缓慢推镜 / 缓慢拉镜 / 手持跟拍 |
| 景别 | ELS 大远景 / LS 远景 / MS 中景 / MCU 近景 / CU 特写 / ECU 大特写 |
| 台词 | `{台词内容}`，无台词写 `{}` |
| 视线落点 | 角色看向哪里 |
| 焦点 | 锁定哪个角色/部位 |
| 稳定性 | 稳定 / 轻微晃动 |

## 引用语法

| 引用 | 写法 | 说明 |
|---|---|---|
| 人物 | `@小夜_正` | 编码必须在 manifest.md 注册 |
| 场景 | `@便利店_夜` | 同上 |
| 道具 | `@黑伞` | 同上 |
| BGM | `@配乐_钩子段.mp3` | 部分版本支持 |

## 硬规则

1. **一段 15 秒一次生成**，不要拆成单镜多次
2. 每镜 10 个字段必填（焦距/机位/构图/运镜/景别/画面/台词/视线落点/焦点/稳定性）
3. `@编码` 放最前面，与段卡 `image_refs` 一一对应
4. 台词写在豆包提示词里，用 `{}` 包裹
5. 声景用 `<>` 包裹，配乐用 `（）` 包裹
6. 末尾加【约束】画面无字幕
