# 🎥 豆包 / Seedance 段级提示词模板

> 适配火山引擎 Seedance 2.0/2.5 + 即梦 AI。**一段 = 一次生成 = 15 秒 = 5–6 镜。**

## 官方公式（段级）

```
段级描述：{场景氛围}。
镜1：{画面}。固定/运镜。
切：镜2：{画面}。固定/运镜。
切：镜3：{画面}。
...
全程声景：{雨声/冰箱声...}。配乐：{钢琴单音...}。
@{编码1} @{编码2} ...
9:16 竖屏，15 秒。
```

## 范例（E01-01，5 镜）

```
雨夜便利店夜归人，冷暖光交界。
镜1：雨夜空荡街道，远处便利店暖光从玻璃透出。固定镜头。
切：镜2：便利店内，小夜在柜台后擦杯子，冷白顶光混合暖黄货架灯。固定镜头。
切：镜3：便利店玻璃门被推开，门铃响，暖黄光溢出。固定镜头。
切：镜4：阿雾站在门口，雨水从黑色湿发梢滴落。固定镜头。
切：镜5：小夜抬头，眼神微怔，镜头缓慢推近到特写。暖黄灯光打在脸上。
全程雨声底噪，室内段冰箱嗡嗡声。配乐：钢琴单音，稀疏混响。
@街道_雨 @小夜_正 @便利店_夜 @便利店门口_夜 @阿雾_正
9:16 竖屏，15 秒，运镜平缓。
不要：变形、闪烁、人物变脸、多余肢体。
```

## 引用语法

| 引用 | 写法 | 说明 |
|---|---|---|
| 人物 | `@小夜_正` | 编码必须在 manifest.md 注册 |
| 场景 | `@便利店_夜` | 同上 |
| 道具 | `@黑伞` | 同上 |
| BGM | `@配乐_钩子段.mp3` | 部分版本支持 |

## 硬规则

1. **一段 15 秒一次生成**，不要拆成单镜多次
2. 镜与镜之间用"切："分隔，每镜 2–4 秒
3. 声景和配乐写在段末，不写在每镜里
4. `@编码` 必须与段卡.md 的 `refs` 数组一一对应
5. 台词不写在豆包提示词里（豆包对口型弱，台词靠后期 TTS 贴）
