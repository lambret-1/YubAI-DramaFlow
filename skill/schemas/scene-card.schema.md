# 🏞️ 场景资产卡 Schema（P3 产物）

> 半自动模式：本卡片**不生成图**，只产出可直接粘到文生图工具的提示词包。
> **资产编码规则**：`<场景名>_<时段>`，例 `便利店_夜`。编码必须在 `manifest.md` 注册。

## 产物格式（markdown）

```markdown
# 场景卡：<场景名>

## <场景编码1>
```
{anchor_en}
<场景描述，空镜，no people，wide establishing shot>
masterpiece, best quality, 8K.
```

## <场景编码2>
```
{anchor_en}
<另一时段场景描述>
masterpiece, best quality, 8K.
```
```

## 规则

1. 每个场景至少出 **1 个主时段**（该场景在全片中实际出现的时段）；可选出 2–3 个时段变体
2. 所有提示词**第一行必须是 `{anchor_en}`**（占位符，P4 生成时替换成真实锚定词）
3. 场景提示词默认 **no people**，人物在 P4 视频生成时单独叠加
4. 每个场景编码一个 `## 子标题`，下面直接跟代码块，不多余字段
